# Frozen Suite C source snapshot

This source snapshot is extracted from the exact notebook qualified in Kaggle
with the sdkparams2 QA16 gate and then used for the C campaign. It preserves
the embedded checkpoint module, shared TypeScript engine and campaign code.
It is separate from the later E-only boundary and parallelism corrections.

The notebook contains source and configuration fingerprints only. It contains
no corpus, answer key, credential or execution output. The original inputs
remain in a private Kaggle dataset. Redistribution rights for the 48 real
sources have not been cleared; hashes and links do not grant those rights.

## Reproduction

Import `runner.ipynb` into a Kaggle Benchmark Task using kaggle-benchmarks 0.6.1.
Supply the matching private inputs at the declared mount, or update only their
operational directory fields. Refresh the real free-quota observation before
execution. Unknown reset times must remain null. Run source setup, definitions,
then the campaign. Keep saved checkpoints for resume; do not combine identities.
This snapshot has no permission to upgrade, top up or switch model providers.

The quota threshold is a conservative local guard, not proof that the provider
quota is exhausted. QA verifies software mechanisms, not model correctness or
pedagogical mastery. Campaign results and incomplete counts are reported
separately after execution; their target is 60 extractions and 240 productions.

The current shared preparer includes later E source corrections and therefore
has a different global harness digest. Do not regenerate this frozen C runner
