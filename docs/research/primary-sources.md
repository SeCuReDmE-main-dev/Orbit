## Politique de preuve

- Une affirmation scientifique cite une source primaire ou un calcul reproductible.
- Un texte généré par modèle n’est jamais une source.
- Une fixture synthétique est étiquetée synthetic.
- Une source inaccessible reste inaccessible, jamais read.
- Une projection ou une inférence est distinguée d’un résultat observé.
