# Side-panel microcopy and accessibility contract

## Status text

- Ready — Choose a source or ask a question.
- Sign-in required — Connect a provider to start this mission.
- Plan ready for review — Nothing has run yet.
- Searching — {used} of {limit} searches used.
- Reading sources — {used} of {limit} pages read.
- Paused — Your mission and counters are saved locally.
- Restored — Continuing from the last confirmed step.
- Budget reached — Review the current evidence before adding more.
- Source unavailable — It remains listed as inaccessible.
- Provider unavailable — Your mission is safe; retry or switch provider.
- 3D unavailable — The numerical and text views remain available.
- Reduced motion enabled — The orbit is shown as steps.

## Requirements

- Every operation works by keyboard without timing-dependent input.
- Focus remains visible and ordered.
- Sliders expose labels, units, values and keyboard alternatives.
- Status changes use a status region without stealing focus.
- Information does not depend on color alone.
- Continuous movement pauses when hidden.
- prefers-reduced-motion selects a stepped or text presentation.
- Errors state what happened, what was preserved and the next action.
