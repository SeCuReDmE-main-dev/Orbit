# HUMAN — using Orbit Companion

1. Open a trusted page.
2. Ask one focused question.
3. Review the plan.
4. Start only when scope and limits make sense.
5. Open important sources before accepting the explanation.
6. Write a prediction before running the orbital lesson.
7. Compare the observation with the prediction.

Animation runs locally. Model calls happen only for explicit research or explanation. Pausing preserves the mission locally. Changing providers transfers the structured mission package, not an assumed hidden session.

An inaccessible source was not read. A rendered orbit is a model result, not an observation. Completed means a software step finished; it does not prove mastery.

Never paste passwords, tokens, personal learner data or private correspondence into a mission intended for sharing.
