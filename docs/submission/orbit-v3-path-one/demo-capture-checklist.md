## Prepare a clean view

Use the exact deployed release intended for the submission. Record URL, release identity, UTC capture time, viewport and preference state in the capture notes. Keep the version distinction visible: application **VERSION V3 / 3.0.0**, approved atom mechanism **2.1.7**.

Crop the application viewport. Exclude unrelated tabs, bookmarks, browser account identity, e-mail, private projects, access tokens and development-console secrets. Use public course content and a clearly identified synthetic artifact for workspace captures. Preserve a separate original screenshot before cropping.

## Keep the captions literal

Prefer short captions that name what is visible: “Module 1: prediction, one changed variable and selected observation” or “The lab exposes twenty-five tools in this recorded context.” A screenshot of a green build establishes that recorded build; learner understanding is examined by explanation and transfer.
