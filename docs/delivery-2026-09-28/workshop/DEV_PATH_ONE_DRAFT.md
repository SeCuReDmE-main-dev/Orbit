# Orbit: checking research conclusions against Sanity Context

> Submission draft. Do not publish until a real report, baseline comparison, public route, and judge walkthrough have been verified. Replace this status note before publication.

Deep research can produce a polished answer whose citations do not support its conclusion. Orbit is a research workspace that keeps the question, plan, source decisions, exact extracts, claims, human review, and report in one versioned dossier. Its central operation is a conclusion check: a reviewer can follow a statement back to an exact retained passage and see where a source is missing, excluded, changed, or contradictory.

For the Sanity Challenge Path One, Orbit's local Codex agent reads a real Sanity Context MCP outline backed by our Knowledge Base, chooses bounded entry paths, reads those entries, and deposits a **proposal**. Sanity is not a decorative content store here: the agent's proposed plan identifies distinctions between providers, product surfaces, background execution, and data-retention conditions from the structured entries. A human must approve the plan before the report stage. The report stage refuses an altered entry digest or an invented quote. A browser agent can also use Orbit's ten WebMCP tools with separate read and proposal consent.

The observed local demonstration used the question “Under which documented conditions can background deep research coexist with zero-data-retention requirements across OpenAI and Google API surfaces?” The agent called `initial_context`, then read `data_retention_and_privacy`, `deep_research/models_and_apis`, and `search_apis/google_grounding`. It produced a pending plan with nine axes and nine screening criteria. **This is a plan result, not yet an approved scientific conclusion.** The trace and importable dossier are in this delivery folder.

The Knowledge Base contains research-method and provider-policy material. It is not a universal scientific source corpus. Orbit labels a Context entry as such; it does not claim to have read the primary documents named inside that entry. The next demonstration must inspect those originals, finish a report, audit its material claims and compare it with a keyword baseline over the same source set. No performance or accuracy advantage is claimed yet.

Orbit uses Astro for the public landing and research workspace, a server-side gateway for the Sanity credential, a local Codex app-server account for its reproducible agent, and a portable evidence dossier for review and export. The landing remains an interactive atom, while the workspace uses five task views rather than a long marketing page. The Studio review module can import a chosen dossier for claim review; it does not silently write private work into the Knowledge Base.
