# Feature graveyard

Excluded from this milestone:

- autonomous publication, submission or deployment;
- paid provider calls;
- ambient access to email, storage, calendars or accounts;
- automatic approval inference;
- multi-provider routing before one adapter passes the contract;
- indefinite conversational memory;
- raw secret storage in checkpoints;
- scientific or operational claims derived from a UI simulation;
- self-modifying gates or budgets;
- silent retries of external writes.

Each item requires a new bounded decision and cannot be revived by provider availability alone.
